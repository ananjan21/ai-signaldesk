# AI SignalDesk Image Asset Prompts

This document contains the complete image-generation brief for AI SignalDesk. Every prompt can be pasted directly into ChatGPT image generation.

## 1. Shared Visual Direction

Use this direction consistently across the complete image set:

- Product: AI SignalDesk, a professional AI market-intelligence dashboard.
- Audience: founders, researchers, AI builders, job seekers, consultants, and content professionals.
- Style: precise editorial technology photography mixed with restrained data-visualization elements.
- Mood: credible, current, analytical, useful, calm, and commercially focused.
- Main colors: white `#FFFFFF`, ink `#111827`, navy `#17324D`, teal `#007F73`, and pale gray `#F5F7F9`.
- Supporting accents: green `#1F7A4D`, amber `#B7791F`, red `#B4233A`, and violet `#4F46E5`.
- Lighting: clean studio or daylight illumination with crisp detail and moderate contrast.
- Composition: uncluttered, strong focal point, generous negative space, no decorative blobs or random ornaments.
- People: inclusive and natural when present; no staged stock-photo expressions.
- Do not generate text inside images. All titles, labels, scores, and buttons must remain HTML.

### Universal Negative Prompt

Append this paragraph to any prompt when the generated result becomes too decorative or inaccurate:

> No words, letters, numbers, logos, watermarks, signatures, fake application interfaces, illegible charts, floating decorative spheres, neon cyberpunk lighting, excessive gradients, purple-dominated palette, dark sci-fi room, humanoid robot, glowing brain, handshake stock photo, generic corporate stock photography, visual clutter, distorted hands, duplicate objects, low resolution, blur, noise, or heavy depth-of-field effects.

## 8. Images Not To Generate

Do not use AI-generated raster images for these interface elements:

- Buttons
- Navigation icons
- Refresh, send, download, search, close, filter, or menu symbols
- Checkboxes, toggles, sliders, and form controls
- Category labels and score badges
- Charts containing real data
- Product screenshots
- Text-based logos

Use HTML/CSS and a consistent icon library such as Lucide for these elements. This keeps controls sharp, accessible, responsive, and able to show hover, loading, disabled, and error states.

## 9. Export Checklist

Before adding any generated image to the app:

1. Confirm there is no accidental text, watermark, copied logo, or signature.
2. Check hands, faces, charts, document edges, and repeated objects for generation errors.
3. Preserve the requested aspect ratio and crop around the focal point.
4. Export web images as WebP and social/email fallbacks as JPEG.
5. Keep a lossless PNG master outside the production bundle when available.
6. Add descriptive HTML `alt` text based on the image's actual meaning.
7. Never place essential instructions or information only inside the image.
8. Test each asset at desktop and mobile card sizes.
9. Use lazy loading for feed images below the first viewport.
10. Record the prompt, generation date, and licensing terms with the source file.
